# 🎮 Weplay - Online Video Game Store

Este proyecto es una aplicación web interactiva desarrollada como parte del curso de Front-End JS. 
El objetivo de la página es que todas aquellas personas interesadas en adquirir videojuegos (en formato físico) para distintas plataformas, puedan hacerlo a través del sitio web.
La estética está inspirada en el mundo gamer, pero siguiendo un estilo futurista y moderno. 

## 🛠️ Tecnologías Utilizadas

Para el desarrollo de este proyecto se emplearon las siguientes herramientas y tecnologías:

* HTML5: Estructura semántica del sitio.
* CSS3: Estética del sitio.
* JavaScript: Se utilizará más adelante para el filtrado de productos, aplicación de efectos en el sitio, carrusel y la tienda.
